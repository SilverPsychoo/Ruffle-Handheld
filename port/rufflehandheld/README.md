## Notes

Ruffle Handheld runs Flash SWF files on ARM64 Linux handhelds. Copy your SWF files into the `flash` folder on the ROM card, then open Ruffle Handheld in Ports to add the games to the menu. For games with extra files, see the [full guide](https://github.com/SilverPsychoo/Ruffle-Handheld#adding-games).

Games are not included. Flash compatibility and controls vary by game and firmware.

Thanks to the [Ruffle contributors](https://github.com/ruffle-rs/ruffle) for the Flash emulator and to the Ruffle Handheld community for testing on handhelds.
